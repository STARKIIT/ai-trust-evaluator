# 1. Overview

## Product Vision

The system is a browser-integrated AI Output Evaluation Layer that analyzes outputs generated by LLM platforms such as:

* Claude
* Gemini
* ChatGPT

and produces structured evaluations for:

* trustworthiness
* reasoning quality
* hallucination risks
* factual grounding
* calibration
* assumptions
* bias/fairness
* task completion
* explainability
* interpretability
* overall reliability

through an interactive side-panel interface.

The architecture is designed as:

*

# Centralized Evaluation Backend

*

# API-Based Intelligence Layer

# 3. Core Architectural Principles

## 3.1 Thin Client Architecture

The browser extension should remain lightweight.

Responsibilities of the extension:

* extract visible content
* render UI
* manage user interactions
* communicate with backend APIs

All intelligence-heavy processing occurs server-side.

---

## 3.2 Independent Evaluation Pipeline

The extension must NOT:

* inject hidden prompts into user chats
* modify Claude/Gemini conversations
* pollute user context windows

Instead:

* responses are independently evaluated externally.

---

## 3.3 Modular Evaluation Design

Each evaluator should function as an independent module.

Benefits:

* scalable
* replaceable
* easier experimentation
* independent iteration

---

## 3.4 Assistive, Not Authoritative

The system should:

* identify risks
* suggest uncertainty
* provide structured evaluation

The system should NOT:

* claim absolute truth
* claim definitive factual correctness

# 10. Scoring System

# 10.1 Scoring Philosophy

Avoid:

* fake precision
* misleading percentages

Prefer:

* LOW
* MEDIUM
* HIGH

or:

* LOW RISK
* MEDIUM RISK
* HIGH RISK

---

# 10.2 Scoring Dimensions

| Dimension     | Purpose             |
| ------------- | ------------------- |
| trust         | overall reliability |
| reasoning     | logic quality       |
| hallucination | unsupported claims  |
| calibration   | certainty alignment |
| factuality    | grounding quality   |
| bias          | fairness            |
| empathy       | emotional quality   |
